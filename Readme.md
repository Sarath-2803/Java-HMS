# Hotel Management System

A desktop-based Hotel Management System developed in Java to streamline hotel operations such as room booking, cancellations, stay extensions, payment processing, and restaurant reservations. The project follows Object-Oriented Programming (OOP) principles and uses PostgreSQL for persistent data storage.

## Features

- Room booking and reservation management
- Booking cancellation
- Stay extension
- Payment processing
- Restaurant reservation management
- Real-time room availability tracking
- Interactive GUI for hotel staff
- Database integration using PostgreSQL

## Getting Started

### Prerequisites

- Java JDK
- PostgreSQL
- VS Code or any Java IDE

### Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/hotel-management-system.git
```

2. Create the PostgreSQL database.

3. Configure the database credentials in the project.

4. Build and run the application.
